# Student Grade Tracker

A simple Java console-based project that calculates a student's total marks, average, grade, and pass/fail status.

## Features

* Accepts student name and marks in 5 subjects
* Validates marks (0–100)
* Calculates total and average
* Assigns a grade
* Displays PASS or FAIL status

## Technologies Used

* Java
* VS Code

## How to Run the Project

### Prerequisites

Install Java JDK on your computer.

### Steps

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal in VS Code.
4. Compile the Java file:

```bash
javac StudentGradeTracker.java
```

5. Run the program:

```bash
java StudentGradeTracker
```

6. Enter the student's name and marks when prompted.

## Sample Input

```text
Tasleem
85
90
78
88
79
```

## Output

The program calculates the total marks, average, grade, and PASS/FAIL status based on the entered marks.
