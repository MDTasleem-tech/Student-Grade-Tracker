# Student Grade Tracker (Java)

A menu-driven Java console application that manages student marks and generates academic performance reports.

## Features

- Add multiple students during one program session
- Enter marks for five subjects
- Validate student names and marks from 0 to 100
- Calculate total and average marks
- Find each student's highest and lowest marks
- Assign grades based on average marks
- Display individual student reports
- Generate a class summary with the number of students, class average, highest mark, lowest mark, and topper
- Store multiple student records using Java `ArrayList` and arrays

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays and ArrayList
- Scanner
- Loops and conditional statements
- Input validation

## How to Run

1. Install the Java JDK.
2. Download or clone this repository.
3. Open a terminal in the folder containing `StudentGradeTracker.java`.
4. Compile the program:

   ```bash
   javac StudentGradeTracker.java
   ```

5. Run the application:

   ```bash
   java StudentGradeTracker
   ```

## Data Storage

Student records are stored in memory while the application is running. Records are not saved permanently after the program closes.
